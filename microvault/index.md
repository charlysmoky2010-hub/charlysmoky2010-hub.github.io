# CSV-Datei vor dem Import prüfen: Dubletten, leere Felder und Prüfschritte

**Eine Datei lässt sich importieren – aber sind die Zeilen plausibel?** Vor einer Hotelstatistik, Inventurliste oder B2B-Auswertung helfen drei einfache Vorprüfungen: identische Zeilen, leere Felder und Spaltenstruktur.

[**Jetzt kostenlos die eigene CSV im Browser prüfen →**](https://microvault.floot.app/csv-datei-pruefen?src=share)

## Fiktives Beispiel

```csv
Vorgang;Datum;Betrag
A-101;2026-10-12;129,00
A-102;2026-10-12;89,00
A-102;2026-10-12;89,00
A-103;2026-10-13;
```

**Was fällt auf?**

1. Die zweite und dritte Datenzeile sind vollständig identisch. Es handelt sich um einen Kandidaten für ein exaktes Duplikat; ob es tatsächlich ein Fehler ist, hängt vom Geschäftsvorgang ab.
2. Im vierten Vorgang fehlt ein Betrag. Das ist ein Hinweis zur Prüfung, keine automatisch festgestellte Geschäftsregelverletzung.
3. Die Datei nutzt Semikolon als Trennzeichen und ein deutsches Dezimalkomma. Das muss bei der Verarbeitung korrekt interpretiert werden.

## Kostenloser Prüfablauf

1. Lade nur eine **zur Verarbeitung freigegebene CSV** hoch – bei MicroVault wird die Datei für die Analyse im lokalen Browser ausgewertet, nicht als Originaldatei an den Server übertragen.
2. Prüfe Anzahl der Zeilen, exakte Duplikate und leere Zellen. Alternativ zuerst die fiktive Beispieldatei verwenden.
3. Lade die kostenlose Kurzübersicht herunter und prüfe die Fundstellen fachlich, bevor Daten verändert werden.
4. **Entferne nie automatisch alle gleichen Zeilen**: Eine legitime wiederholte Buchung kann identisch aussehen.
